## Context

gitのブランチ名を生成するコマンドラインアプリケーションを開発します。ユーザーは開発したい機能を説明すると、LLM（ChatGPT）を使用して適切なブランチ名の案を取得できます。接頭辞（feature/, hotfix/, topic/など）は事前に設定可能で、生成されるブランチ名に自動的に付与されます。

## Goals / Non-Goals

### Goals
- npm install -gでインストール可能なCLIツールとして提供
- 設定可能な接頭辞の管理
- 対話的な機能説明の入力
- ChatGPT APIを使用したブランチ名生成
- シンプルで使いやすいインターフェース

### Non-Goals
- 複数のLLMプロバイダーのサポート（初期はChatGPTのみ）
- ブランチ名の履歴管理機能
- GUIインターフェース
- ブランチの自動作成機能

## Decisions

### Decision: TypeScriptを使用
- **理由**: 型安全性とメンテナンス性の向上
- **代替案**: JavaScript（型安全性が低い）

### Decision: inquirerを使用した対話的入力
- **理由**: ユーザーフレンドリーなCLIインターフェースの実現
- **代替案**: readline（低レベルで実装が複雑）

### Decision: 設定ファイルはホームディレクトリに保存
- **理由**: グローバルインストールでも設定を保持できる
- **代替案**: プロジェクトローカルの設定（グローバルツールには不適切）

### Decision: OpenAI API（ChatGPT）を使用
- **理由**: 広く使われており、APIが安定している
- **代替案**: 他のLLMプロバイダー（初期はChatGPTに集中）

### Decision: 設定ファイル形式はJSON
- **理由**: シンプルで読み書きが容易
- **代替案**: YAML、TOML（JSONで十分）

## Risks / Trade-offs

### Risk: APIキーの管理
- **Mitigation**: 環境変数での管理を推奨、設定ファイルには保存しない

### Risk: API呼び出しのコスト
- **Mitigation**: ユーザーにAPIキーを設定してもらうことで、コストはユーザー負担

### Risk: ネットワークエラー時の動作
- **Mitigation**: 適切なエラーメッセージとリトライ機能の実装

### Risk: 生成されるブランチ名の品質
- **Mitigation**: プロンプトエンジニアリングで品質向上を図る

## Migration Plan

新規プロジェクトのため、マイグレーションは不要です。
